================================================================================
Stable Fluids — 6 kernels only (+ optional Init + Export)
GPU / Niagara Simulation Stage = one kernel pass over Grid2D
================================================================================

Solver order (Always, except Init):

  0 Init         On Simulation Reset | zeros (Niagara only, not a Stam kernel)
  1 Inject       add force + density source          NumIter=1
  2 Advect       semi-Lagrangian u + d               NumIter=1
  3 Diffuse      implicit viscosity + dens diffusion NumIter=20
  4 Divergence   div field, p=0                      NumIter=1
  5 Pressure     Jacobi Poisson                      NumIter=20
  6 Project      u -= grad p                         NumIter=1
  7 ExportRT     Grid → RT (engine output, not Stam) NumIter=1

DO NOT create: DiffuseVel/Dens, AdvectVel/Dens, DivA/DivB, double Project.

Paper-style order used here:
  force → advect → diffuse → project(div,pressure,grad)
(GDC double-project is NOT used — that would need more kernels.)

--------------------------------------------------------------------------------
User params (AScreenFluidActor)
--------------------------------------------------------------------------------
  ClickUV, InjectForce (Vec2), DensitySrc, InjectPulse, ClickRadius
  Dt, GridN, Viscosity, Diffusion, VelocityRT

Texel = 1/GridN
Neighbor UV = UnitToUV ± Texel, Saturate, Sample Previous

Every solver Custom:
  Virtual Include:
    1) /Project/ScreenFluid/StageCommon.ush
    2) /Project/ScreenFluid/StageXXXX.ush

Map Get/Set StackContext names: Velocity, Density, Pressure, Divergence

================================================================================
1 Inject
================================================================================
SF_Inject(UnitToUV, ClickUV, InjectForce, DensitySrc, Radius, InjectPulse, Dt, PrevVelocity, PrevDensity, PrevPressure, PrevDivergence, OutVelocity, OutDensity, OutPressure, OutDivergence);

UnitToUV=ExecutionIndexToUnit.xy
ClickUV=User.ClickUV  InjectForce=User.InjectForce
DensitySrc=User.DensitySrc  Radius=User.ClickRadius
InjectPulse=User.InjectPulse  Dt=User.Dt
Prev* = StackContext.*  →  Out* = StackContext.*

================================================================================
2 Advect  — MUST match this call (8 pins)
================================================================================
// Graph: UV_back = Saturate(UnitToUV - Dt * StackContext.Velocity)
//        SampleVel  = SamplePrevious Velocity  @ UV_back
//        SampleDens = SamplePrevious Density   @ UV_back
SF_Advect(SampleVel, SampleDens, PrevPressure, PrevDivergence, OutVelocity, OutDensity, OutPressure, OutDivergence);

================================================================================
3 Diffuse  (NumIterations=20) — MUST match this call (20 pins)
================================================================================
SF_Diffuse(CenterVel, VelL, VelR, VelD, VelU, CenterDens, DensL, DensR, DensD, DensU, Dt, Viscosity, Diffusion, GridN, PrevPressure, PrevDivergence, OutVelocity, OutDensity, OutPressure, OutDivergence);

CenterVel=StackContext.Velocity  CenterDens=StackContext.Density
Vel*/Dens* = SamplePrevious neighbors
Dt/Viscosity/Diffusion/GridN = User.*

================================================================================
4 Divergence — MUST match this call (12 pins)
================================================================================
SF_Divergence(PrevVelocity, VelL, VelR, VelD, VelU, PrevDensity, PrevPressure, GridN, OutVelocity, OutDensity, OutPressure, OutDivergence);

PrevVelocity=StackContext.Velocity  Vel*=neighbor Velocity
PrevDensity=StackContext.Density  PrevPressure=StackContext.Pressure (ignored)
GridN=User.GridN
(OutPressure forced to 0 inside kernel)

================================================================================
5 Pressure  (NumIterations=20)
================================================================================
// Stam: p = (Σp + div)/4  when div = -0.5/N*((uR-uL)+(vU-vD))
// (NOT (Σp - div)/4 — that is for positive-divergence convention)
SF_Pressure(PressL, PressR, PressD, PressU, PrevDivergence, PrevVelocity, PrevDensity, OutPressure, OutVelocity, OutDensity, OutDivergence);

Press*=SamplePrevious Pressure
PrevDivergence=StackContext.Divergence (fixed rhs)

================================================================================
6 Project — MUST match this call
================================================================================
SF_Project(PrevVelocity, PressL, PressR, PressD, PressU, PrevDensity, PrevPressure, PrevDivergence, GridN, OutVelocity, OutDensity, OutPressure, OutDivergence);

PrevVelocity=StackContext.Velocity
Press*=SamplePrevious Pressure neighbors
GridN=User.GridN


================================================================================
ExportRT (optional 7th stage for PP)
================================================================================
SF_ExportRT(PrevVelocity, PrevDensity, OutColor);
Iteration=FluidGrid; SetRenderTargetValue → Target DI
